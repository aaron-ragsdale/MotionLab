06 / Machine Learning Studio

Build one dataset, train the algorithms you choose, compare results and export any trained classifier for a compatible controller. No second training step is needed.

Learn more about training choices

Static recognition uses one frame; dynamic recognition uses a sliding window of movement. Choose relevant landmarks to reduce input size. Include a Neutral class and record varied independent takes. Random forest learns decision rules; KNN compares examples; nearest centroid compares class averages; linear SVM learns maximum-margin boundaries and RBF SVM learns nonlinear boundaries. Scores are not calibrated probabilities. Read the learning guide.

5 / Save and reuse

The v2 model contains the detector configuration, feature schema, class names and algorithm parameters. KNN and RBF SVM may contain example feature vectors. A future compatible extension maps predicted labels to commands; this studio does not send game inputs.

Privacy: the camera and inference run on this device. The browser downloads MediaPipe runtime and model assets from public CDNs. Image coordinates are estimates, and world landmarks are inferred relative to the hips, not calibrated camera-space measurements. Hand points are wrist, pinky, index and thumb; feet have ankle, heel and foot index. The original pose explorer uses pose hand points; the portable controller lab also supports the dedicated 21-point Hand Landmarker.
