Learn more: how to train a controller

1. Choose tracking: Hands for finger gestures; pose for body positions and movement; both when you need fine hand details and body motion. Combined tracking costs more processing time.

2. Choose recognition: Static uses one frame (pointing, fist, leaning). Dynamic uses recent movement history (punch, swipe, swing). Start with 200–300 ms for quick actions or 500–1000 ms for larger motions. A long window can provide more context but does not guarantee better responsiveness.

3. Define classes: Name any actions you want, plus Neutral for no command. Record separate takes at different speeds and positions. Start moving when the countdown ends. Aim for 10–20 takes per class.

4. Select an algorithm: Random forest learns decision rules; K-nearest neighbors compares new examples with saved examples; nearest centroid compares against an average example of each class. Compare held-out accuracy on the same data. KNN exports landmark examples as part of the model.

5. Test: Stride controls how frequently predictions update; score threshold suppresses uncertain predictions. These can change without retraining, unlike the movement window. Scores are not calibrated probabilities.

6. Export: Download your model. A future controller extension will read your class names and let you assign keys or commands. No game commands are sent by this lab yet.

Temporal inputs are resampled to 30 Hz. Window length is fixed when training; prediction stride and confidence can be adjusted afterward. A dynamic take captures one movement after a countdown.

Privacy: the camera and inference run on this device. The browser downloads MediaPipe runtime and model assets from public CDNs. Image coordinates are estimates, and world landmarks are inferred relative to the hips, not calibrated camera-space measurements. Hand points are wrist, pinky, index and thumb; feet have ankle, heel and foot index. The original pose explorer uses pose hand points; the portable controller lab also supports the dedicated 21-point Hand Landmarker.
